## Naoii について

Naoii は、言語学習者が自然な表現を練習するための多言語コミュニティです。文法の正しさだけでなく、表現の自然さ、トーン、文脈の適切さを追求します。

短いモーメントでも長い記事でも、投稿すればコミュニティから修正案が届きます。各修正には説明とトーンの注釈が付いており、何を変更すべきかだけでなく、なぜ変更すべきかも理解できます。

## 設計理念

教科書的な正しさよりも、実際の表現が重要です。Naoii は3つの考え方に基づいています：

- **本物の表現** — 実際に使いたい文章で練習する
- **コミュニティのフィードバック** — ネイティブや上級者から、文法だけでなく文脈を学ぶ
- **個人の蓄積** — 採用した修正をライブラリに保存し、復習を通じて自分の力に変える

量より質を重視します。修正が採用されると修正者に評価ポイントが付与され、質の高いフィードバックが促進されます。

## 主な機能

- **モーメントと記事** — 短い表現と長文の2種類のコンテンツ形式
- **修正システム** — 単語単位の差分表示、説明、トーン注釈付き
- **採用と評価** — 最適な修正を採用し、修正者に +10 評価ポイントを付与
- **表現ライブラリ** — 採用した修正を保存し、間隔反復復習とプライベートタグで管理
- **通知** — 修正、採用、評価の変動をリアルタイムで通知
- **通報と管理** — 不適切なコンテンツの通報、管理ダッシュボードと分析機能
- **トピックとイベント** — コミュニティのチャレンジやテーマ別ディスカッションに参加
- **3言語 UI** — 中国語、英語、日本語インターフェース
- **ダークモード**

## 使い方

1. **書く** — 学習中の言語で表現を書く
2. **修正を受ける** — コミュニティから差分・説明・トーン注釈付きの修正が届く
3. **採用する** — 最も役立つ修正を採用し、修正者に評価ポイントを付与
4. **保存する** — ライブラリに保存して後で復習
