## 关于 Naoii

Naoii 是一个帮助语言学习者练习自然表达的多语言社区。在这里，你不仅追求语法正确，更关注表达是否地道、语气是否恰当、语境是否合适。

无论是简短的瞬间记录，还是较长的文章创作，你都可以发布出来，接受社区的修改建议。每一份修改都附有解释和语气标注，让你知其然，更知其所以然。

## 设计理念

真实的表达远比书本上的正确语法更重要。Naoii 围绕三个核心理念构建：

- **真实表达** — 练习那些你真正想说的话，而非教科书例句
- **社区反馈** — 向母语者和高阶学习者学习，他们解释的是语境，而不只是语法
- **个人积累** — 将优质修改保存到个人表达库，通过间隔复习内化为自己的能力

我们追求修改的质量而非数量。采纳修改会为修改者增加声望值，以此来激励有深度的反馈。

## 核心功能

- **瞬间与文章** — 两种内容类型，满足短表达和长文写作需求
- **修正系统** — 逐词对比展示，附带解释和语气标注
- **采纳与声望** — 采纳最佳修改，为修改者增加 +10 声望
- **表达库** — 保存已采纳的修改，支持间隔复习和私有标签
- **通知中心** — 实时获取修改、采纳和声望变动的提醒
- **举报与管理** — 举报不当内容，提供管理后台与数据看板
- **话题与活动** — 参与社区话题挑战和限时活动
- **三语言界面** — 支持中文、英文、日文
- **深色模式**

## 工作方式

1. **写** — 用你正在学习的语言写下一段表达
2. **改** — 社区成员帮你修改，附上逐词对比、解释和语气标注
3. **采纳** — 选择最有帮助的修改并采纳，授予修改者声望
4. **存** — 保存到个人表达库，随时复习
